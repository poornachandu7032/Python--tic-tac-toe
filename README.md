# ❌⭕ Python Command-Line Tic-Tac-Toe

A fully functional, 2-player Tic-Tac-Toe game that runs entirely in the terminal. This project demonstrates complex state management and game loop logic in Python.

## ✨ Features
- **Two-Player Mode:** Alternates turns seamlessly between Player X and Player O.
- **Interactive Board:** Displays a clean 3x3 grid and updates dynamically after every move.
- **Input Validation:** Prevents users from picking an invalid number, a filled cell, or typing letters.
- **Smart End-Game Detection:** Automatically detects wins across all 8 lines (rows, columns, diagonals) and detects a draw if the board fills up.
- **Replayability:** Prompts the user to play again, resetting the board and score cleanly.

## 🚀 How to Run
1. Ensure you have Python 3 installed.
2. Clone this repository or download the file.
3. Open your terminal or command prompt.
4. Run:
   ```bash
   python tic_tac_toe.py
